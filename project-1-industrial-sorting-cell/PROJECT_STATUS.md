# Project Status

## Release

Design package v0.1

## Status

Engineering logic and documentation are complete enough for implementation and commissioning.

## Not Yet Verified

The Ladder networks have not been compiled in CODESYS in this execution environment.
The Factory I/O scene has not been runtime tested in this execution environment.
The final Modbus address mapping must be verified against the exact CODESYS and Factory I/O versions installed on the commissioning PC.

## Definition of Done

The project should be marked Verified only after all acceptance tests pass and the repository contains screenshots or video evidence of:

1. CODESYS online Ladder monitoring.
2. Factory I/O automatic sorting.
3. High box routed right and low box routed left.
4. A deliberately injected timeout fault.
5. Successful controlled reset.
6. Production counters changing online.
