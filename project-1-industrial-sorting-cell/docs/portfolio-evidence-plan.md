# Portfolio Evidence Plan

Before publishing the repository, capture the following evidence.

1. Factory I/O overview showing the complete cell.
2. CODESYS project tree.
3. Online Ladder Network for Run latch and permissive.
4. Online Ladder Network for one sequence transition.
5. Modbus TCP driver connected indication.
6. High box routed to right conveyor.
7. Low box routed to left conveyor.
8. Fault injection and latched alarm.
9. Manual recovery or reset sequence.
10. Counter values after a multi cycle test.

## Recommended Demo Video

Target 60 to 90 seconds.

Opening: architecture and objective.

Middle: one high and one low sorting cycle.

Fault segment: intentionally create one jam and show the fault latch.

Closing: show CODESYS online monitoring and counters.

## Recommended Resume Bullet

Developed and commissioned a virtual industrial sorting cell using CODESYS Ladder and Factory I/O over Modbus TCP, implementing state based sequencing, interlocks, height based routing, fault timeouts, manual recovery, and production diagnostics.

Do not use the word commissioned until the acceptance test plan has actually been completed.
