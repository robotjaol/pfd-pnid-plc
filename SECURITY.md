# Security Policy

## Supported Versions

The project is currently in active development. Please report vulnerabilities for
all current repository content and any published release branch that is actively
maintained.

## Reporting a Vulnerability

Please report security issues privately through the repository maintainers.

- Use GitHub Security Advisories if available for the repository.
- If not available, contact the project maintainer directly through the repository's
  configured contact method.
- Do not open public issues for security vulnerabilities.

Please include:

- A concise description of the issue
- Affected files, components, or project area
- Steps to reproduce or exploit the issue
- Severity assessment, if known
- Any suggested remediation or mitigation

We will acknowledge the report as quickly as possible and work toward a fix or
responsible disclosure timeline.

## Disclosure Expectations

We ask reporters to allow a reasonable time for remediation before they disclose
vulnerability details publicly, so the project maintainers can address the issue
safely.
