# Contributing

Thanks for your interest in improving this repository.

## How to contribute

1. Fork the repository and create a branch for your change.
2. Keep the scope focused and aligned with the project goals.
3. Document the engineering intent behind process, PLC, or simulation changes.
4. Add or update supporting documentation when behavior changes.
5. Open a pull request with a clear summary and validation notes.

## Repository expectations

- Prefer clear, reviewed changes over large unreviewed refactors.
- For industrial control work, explain the engineering reason and expected behavior.
- Update relevant documentation when changing requirements, architecture, or test plans.
- Keep examples reproducible and readable for other engineers.

## Documentation standards

- Use Markdown for documentation.
- Prefer concise structure with headings, lists, and diagrams when helpful.
- Link to relevant modules, documents, and project assets.

## Pull request checklist

- [ ] The change is scoped and explained clearly.
- [ ] Documentation is updated where needed.
- [ ] The repository structure remains understandable.
- [ ] The change does not contradict existing engineering intent.

## Questions

Open a GitHub discussion or issue if you need clarification before making a change.
